# ⚔️ Gwent Companion

Gwent Companion est un calculateur de score pour le **Gwynt de The Witcher 3**. Il permet de calculer automatiquement le score de chaque joueur en prenant en compte les effets des cartes et de la météo.

## Fonctionnalités

- Calcul automatique des scores.
- Gestion des effets météo.
- Ajout de cartes **Normales**, **Héros**, **Spéciales**, **Bonus de moral**, **Jaskier** et **Lien étroit**.
- Personnalisation du nom des joueurs.

## Utilisation

1. Personnalisez le nom des joueurs (facultatif).
2. Sélectionnez les effets météo actifs.
3. Ajoutez les cartes en indiquant :
   - la ligne (mêlée, distance ou siège) ;
   - la puissance ;
   - le type de carte.
4. Les scores sont calculés automatiquement.

## Lancer le projet

```bash
npm install
npm run dev
```
